# Output Directory

This directory holds regenerable project outputs. Generated files are ignored by git except for README files.

| Path | Contents |
|---|---|
| `figures/` | Descriptive and model figures. |
| `tables/` | Connector rankings, validation tables, and model results. |
| `logs/` | Script logs and run diagnostics. |
| `memo/` | Short feasibility memos and first-stage notes. |
