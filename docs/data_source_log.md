## Current Decision

The data strategy is now viable for a first structural version plus a separate extensive-margin evidence section that directly disciplines the A/B/C welfare-bound design.

- Scenario A keeps the MP margin at `hgamma = 1` and uses trade data to discipline trade-only connector access.
- Scenario B `hgamma` should be disciplined by OECD Analytical AMNE through 2020 and bridged with BEA U.S. MNE activity where country-industry cells are usable.
- Scenario C should be disciplined by total FDI flows, BEA direct-investment country-industry evidence, fDi Markets project-level greenfield announcements, BEA/AMNE affiliate expansion, and production-side expansion evidence.
- fDi Markets remains a possible later project-level source but is explicitly excluded from the current batch.
- The Du-Wang counterfactual should still be described as intensive-margin welfare accounting. Scenario C is an upper-bound proxy for total MP adjustment; it is not an endogenous prediction of the Du-Wang model and not a structural entry-margin welfare estimate.
