This directory is reserved for harmonized analysis-ready data. It currently contains no completed analysis panel.

The next build stage should merge source-specific interim outputs through explicit country, sector, product, and time concordances. Every processed output must be reproducible from `data/interim/`, documented by a build script, and retain source/provenance fields needed to audit aggregation and suppression.
